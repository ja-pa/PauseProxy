Compare a downloaded or installed certificate

On Windows, open certmgr.msc → Trusted Root Certification Authorities → Certificates → PauseProxy Development CA → Details → Thumbprint. Compare it with the SHA-1 value above. For a computer-wide installation, use certlm.msc. A downloaded certificate can also be opened to view Details → Thumbprint.

On Android, open the installed user CA in Security → Trusted credentials (menu names vary) and compare its SHA-256 fingerprint, if shown. Ignore spaces, colons and letter case when comparing.

To check a downloaded PEM or an exported Base-64 certificate with OpenSSL:

openssl x509 -in pauseproxy-ca.pem -noout -fingerprint -sha256

These values identify the certificate itself; a hash of the PEM file will differ. A matching fingerprint confirms the same certificate, but does not confirm that the device trusts it. For authenticity, compare against this page opened directly on the server or an independently obtained fingerprint.

Refresh PAC after changing domains

The server updates PAC immediately. On Windows, turn the setup script off and on in proxy settings. On Android, set Wi-Fi proxy to None, save, then restore automatic configuration with the same URL. Close affected tabs and reopen the site. After changing media exceptions, restart the browser to close existing connections.
